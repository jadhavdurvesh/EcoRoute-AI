# EcoRoute AI — 60–90 Second Demo

1. Open the dashboard and explain that EcoRoute AI helps users compare the predicted emissions of different ways to make the same trip.
2. Set an example trip such as 8 km, one passenger, moderate traffic and light rain.
3. Show the six transport modes and the AI-predicted emissions chart.
4. Point to the recommendation card and explain the estimated emissions avoided compared with a car trip.
5. Change the passenger count and traffic intensity and show how the predictions change.
6. End by explaining that the prototype is trained on transparent synthetic data and is designed to be retrained on validated city-specific mobility data for deployment.
